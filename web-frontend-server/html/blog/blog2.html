Bài 2: Kiến trúc Nginx Reverse Proxy & Load Balancer

Tác giả: Nhóm Đồ Án Cloud Computing

API Gateway đóng vai trò là cửa ngõ duy nhất (Single Point of Entry) tiếp nhận mọi request từ client qua cổng 80, thực hiện điều hướng path-based routing đến các microservice nội bộ.

Đặc biệt, hệ thống sử dụng thuật toán Round Robin để cân bằng tải lưu lượng truy cập giữa hai web frontend container, nâng cao tính sẵn sàng cao (High Availability).
