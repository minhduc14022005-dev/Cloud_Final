Bài 1: Giới thiệu hệ thống MyMiniCloud với 9 server

Nhóm đồ án Cloud Computing

Hệ thống MyMiniCloud mô phỏng một nền tảng Cloud thu nhỏ với đầy đủ các thành phần hạ tầng cốt lõi: Web Server, Backend API, Database, Identity & Auth, Object Storage (S3-like), DNS, Monitoring và API Gateway.

Mỗi dịch vụ được cô lập trong container Docker riêng biệt và giao tiếp an toàn thông qua mạng bridge nội bộ cloud-net.
